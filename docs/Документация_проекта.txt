2. Цель и назначение системы
Проект представляет собой настольное приложение для демонстрации базовой автоматизации магазина:
- авторизация пользователей;
- просмотр товаров и заказов;
- поиск в реальном времени;
- сортировка;
- управление данными (CRUD) для администратора.

3. Область применения
Система может использоваться как:
- учебный проект по SQL и Python;
- демонстрация ролевой модели в интерфейсном приложении;
- пример разделения логики по ролям пользователей.

4. Архитектура приложения
4.1 Общая структура:
- main.py: точка входа.
- db.py: подключение к MySQL.
- auth/: авторизация и регистрация.
- roles/: отдельные окна для ролей guest/user/manager/admin.
- ui/: формы интерфейса.
- data/: изображения товаров.
- sql/: SQL-скрипт создания БД и наполнения.

4.2 Логика ролей:
- guest: просмотр товаров.
- user: просмотр товаров.
- manager: товары и заказы, поиск, сортировка.
- admin: товары и заказы, поиск, сортировка, CRUD.

5. Проектирование базы данных
5.1 Используемая БД:
- Имя БД: fabric_store_2

5.2 Таблицы:
- roles
- users
- categories
- products
- order_statuses
- orders
- order_items

5.3 Обоснование 3НФ:
- Справочники вынесены отдельно (roles, categories, order_statuses).
- Основные сущности связаны внешними ключами.
- Состав заказа хранится в отдельной таблице order_items.

8. Описание интерфейса
8.1 Окно регистрации:
- ввод логина и пароля;
- переход в окно входа;
- вход как гость.

- ввод логина и пароля;
- определение роли и открытие нужного окна.

8.3 Окно гостя и пользователя:

8.4 Окно менеджера:
- вкладка товаров;
- вкладка заказов;

- сортировка через ComboBox.

8.5 Окно администратора:
- функции менеджера;
- кнопки создать/редактировать/удалить;
- CRUD для товаров и заказов.

10. SQL-скрипт и данные
Скрипт sql/fabric_store_3nf.sql выполняет:
- создание БД fabric_store_2;
- создание таблиц;
- массовую вставку тестовых данных.

11. Инструкция по запуску
1) Открыть терминал в папке проекта.
2) Выполнить: mysql -u root -p < sql/fabric_store_3nf.sql
3) Выполнить: pip install -r requirements.txt
4) Проверить параметры подключения в db.py.
5) Выполнить: python main.py

13. Сценарии тестирования
13.1 Проверка роли manager:
- вход под manager;
- поиск по названию товара;
- сортировка по цене;
- переход на вкладку заказов и поиск по статусу.

13.2 Проверка роли admin:
- добавление товара;
- изменение цены товара;
- удаление товара;
- создание заказа;
- изменение статуса заказа;
- удаление заказа.

14. Заключение
В проекте реализована простая ролевая система и работа с MySQL через SQL-запросы.
Архитектура проекта позволяет наращивать функциональность без изменения базовой структуры.
