# Fabric Store Admin Project

Отдельный учебный проект на `PyQt6 + MySQL` для работы с товарами и заказами магазина одежды.  
Проект находится в собственной папке и не изменяет старый код.

## Назначение проекта

Приложение демонстрирует:
- авторизацию пользователей по ролям;
- просмотр товаров и заказов;
- поиск в реальном времени;
- сортировку данных;
- базовые операции CRUD (для администратора).

## Структура проекта

- `main.py` — точка входа в приложение.
- `db.py` — подключение к MySQL (простой конфиг как в оригинале).
- `auth/`
  - `registration.py` — регистрация и вход как гость;
  - `login.py` — авторизация и переход к роли.
- `roles/`
  - `guest.py` — просмотр товаров;
  - `user.py` — просмотр товаров;
  - `manager.py` — просмотр товаров/заказов + поиск + сортировка;
  - `admin.py` — просмотр товаров/заказов + поиск + сортировка + CRUD.
- `ui/` — формы входа, регистрации, гостя и пользователя.
- `manager_win.ui` — общая форма менеджера/админа (вкладки товары/заказы).
- `data/` — изображения товаров.
- `sql/fabric_store_3nf.sql` — SQL-скрипт создания БД и тестовых данных.
- `docs/Документация_проекта.docx` — подробная документация проекта.

## База данных

Используется БД `fabric_store_2`.

Таблицы:
- `roles`
- `users`
- `categories`
- `products`
- `order_statuses`
- `orders`
- `order_items`

Скрипт `sql/fabric_store_3nf.sql`:
- пересоздает БД;
- создает все таблицы;
- заполняет таблицы тестовыми данными через обычные множественные `INSERT`.

## Роли и возможности

- `guest`
  - просмотр списка товаров с изображениями.
- `user`
  - просмотр списка товаров с изображениями.
- `manager`
  - просмотр товаров и заказов;
  - поиск по строке в реальном времени;
  - сортировка.
- `admin`
  - все возможности `manager`;
  - создание/редактирование/удаление товаров;
  - создание/редактирование/удаление заказов.

## Быстрый запуск

1. Перейти в папку проекта:

```bash
cd /Users/alexeysharunov/Desktop/DemoPreparation/fabric_store_admin_project
```

2. Создать БД и таблицы:

```bash
mysql -u root -p < sql/fabric_store_3nf.sql
```

3. Установить зависимости:

```bash
pip install -r requirements.txt
```

4. Проверить настройки подключения в `db.py`:

- host: `localhost`
- user: `root`
- password: `anksoonamoon`
- db: `fabric_store_2`

5. Запустить приложение:

```bash
python main.py
```

## Типовой сценарий проверки

1. Войти под `manager` и проверить:
   - поиск по товарам;
   - переключение на вкладку заказов;
   - сортировку.
2. Войти под `admin` и проверить:
   - создание товара;
   - изменение цены товара;
   - удаление товара;
   - создание/изменение/удаление заказа.
